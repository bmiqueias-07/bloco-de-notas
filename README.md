
# NoteFácil 📝

O NoteFácil é um bloco de notas simples para escrever, salvar, organizar anotações de atividades escolares ou até pessoais.

## Funcionalidades
- Criar anotações com título e texto.
- Salvar anotações no navegador.
- Excluir anotações.
- Visualizar anotações salvas.

## Tecnologias utilizadas
- HTML
- CSS
- JavaScript

## Objetivo
Projeto desenvolvido para praticar programação e criação de páginas web.
